# Smart Civic Complaint & Monitoring System — Telangana

## Problem
Urban civic issues like garbage overflow, potholes, and streetlight failures are not resolved efficiently due to lack of transparency and prioritization.

## Solution
A web-based platform allowing citizens to report issues, track progress, and enabling authorities to manage complaints with data-driven insights.

## Features
- Complaint submission with image & location
- Real-time status tracking
- Priority-based resolution
- Admin analytics dashboard
- Civic heatmap visualization

## Tech Stack
Frontend: HTML, CSS, JavaScript (React)
Backend: Node.js / Flask (Prototype)
Database: MongoDB / MySQL

## How to Run
npm install
npm start
